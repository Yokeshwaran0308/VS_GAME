# 🎮 VS_GAME - Classic Arcade Web Games

A collection of interactive, browser-based arcade and puzzle games hosted directly on GitHub Pages.

🔗 **[Play All Games Live Here](https://yokeshwaran0308.github.io/VS_GAME/)**

---

## 🕹️ Included Games

* **🐍 Snake Game:** Navigate the grid, collect food, and grow without crashing into walls or your own tail.
* **❌⭕ Tic-Tac-Toe:** Challenge the AI in a classic grid battle.
* **🧱 Breakout:** Smash all the bricks with the bouncing ball using your paddle.
* **🔢 Number Game:** Test your logic and guessing skills against dynamic numeric challenges.
* **🚀 Space Dodge:** Maneuver through space and dodge incoming obstacles.

---

## 🛠️ Built With

- **Python & Pygame** – Game development and game logic
- **Pygbag** – Converts Pygame games to browser-compatible web builds
- **HTML5 & CSS3** – Website structure and styling
- **GitHub Pages** – Web hosting and deployment
